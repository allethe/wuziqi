
## 1. Architecture Design
纯前端项目，使用 React + Vite + Tailwind CSS

## 2. Technology Description
- Frontend: React@18 + tailwindcss@3 + vite
- Initialization Tool: vite-init
- Backend: None (纯前端项目)

## 3. Route Definitions
| Route | Purpose |
|-------|---------|
| / | 游戏主页面 |

## 4. Data Model
无需后端数据库，游戏状态完全在前端管理

## 5. Core Components
- GameBoard: 棋盘组件，负责渲染和落子
- GameControls: 操作按钮组件
- GameStatus: 游戏状态显示组件
- useGame: 游戏逻辑自定义 Hook
